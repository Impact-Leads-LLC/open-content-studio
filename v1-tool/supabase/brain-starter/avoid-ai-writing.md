# Avoid AI Writing

Run this as the final pass on anything written in the owner's name. The goal is writing that sounds like a person wrote
it: direct, specific, varied in rhythm, with no patterns that signal machine generation.

## Words: always replace

| Replace | With |
|---|---|
| delve / delve into | look at, dig into |
| leverage (verb), utilize | use |
| robust | strong, solid |
| comprehensive | thorough, complete |
| seamless / seamlessly | smooth, easy |
| cutting-edge | latest, newest |
| meticulous | careful, detailed |
| holistic | complete (or say what's included) |
| actionable | practical, concrete |
| impactful | effective (or describe the impact) |
| transformational | (name the specific change) |
| paradigm | model, approach |
| embark, commence | start |
| testament to, underscores | shows |
| landscape, realm (metaphor) | field, industry |
| vibrant, thriving, bustling | (describe it, or cite a number) |
| pivotal | important, key |
| game-changer | (say what changed) |
| best practices | what works |
| in order to | to |
| due to the fact that | because |
| serves as | is |
| deep dive / dive into / unpack | look at, explain |
| at its core | (cut it and state the thing) |

## Words: flag when two or more appear together

harness, navigate, foster, elevate, unleash, streamline, empower, bolster, spearhead, resonate, revolutionize,
facilitate, nuanced, crucial, multifaceted, ecosystem, myriad, plethora, cultivate, cornerstone, paramount, poised

## Sentence and structure patterns

- **Em dashes:** none. Use commas, periods, or two sentences.
- **Bold overuse:** strip it. Lead the sentence with the important thing instead.
- **Uniform sentence and paragraph length:** vary it. Some paragraphs are one sentence.
- **Formulaic openings** ("In today's fast-moving world..."): start with the point.
- **Bullet-heavy sections:** turn them into prose unless the content really is a list.
- **"It's not X, it's Y":** state the thing directly.
- **Rhetorical question openers** ("So why should you care?"): say the answer.
- **"Let's" openers** ("Let's break this down"): start with the point.
- **Chatbot artifacts** ("I hope this helps!", "Great question!"): remove.
- **Vague attributions** ("Studies show"): name the source or drop it.
- **Generic conclusions** ("The future looks bright"): cut, or make it specific.
- **Significance inflation** ("marking a pivotal moment"): state what happened.
- **Numbered list inflation** ("Five things to know"): only when there really are five.
- **Confidence phrases** ("Interestingly," "Importantly," "Undoubtedly"): state the fact.
- **Synonym cycling:** if the right word is the same word, repeat it.

## Transitions to cut

Moreover, Furthermore, Additionally, It's worth noting, Here's what's interesting, In conclusion, When it comes to,
At the end of the day, That being said.

## The rhythm check

Read it aloud. Human writing has varied sentence length, opinions, deliberate repetition of the right word, and the odd
sentence that starts with "And" or "But". Don't sand away all personality: the goal is writing that sounds like the
owner, not a cleaned-up AI.

## Patch or start over

Five or more flagged words across categories, three or more structural problems, or uniform sentence and paragraph
length throughout means the structure itself is machine-made. State the core point in one sentence, then rebuild.
