# Example: the kit's parts

Four slides that show the parts of the kit, with placeholder copy (a made-up guest, "The Show"
and "@yourhandle"). They are references for building, not a deck to post.

| Slide | Format | Parts |
|---|---|---|
| `01-side-by-side` | Side-by-side | `.compare`, `.email`, `.mark`, `body.soft` |
| `02-phone-thread` | Artifact mockup | `.phone`, `.thread`, `.bubble.me`, `.bubble.them` |
| `03-steps` | Process | `.steps`, `.num` |
| `04-stat` | Stat | `.display`, `.dots`, `body.navy` |

Render with `python3 ../../scripts/render.py slides`.
