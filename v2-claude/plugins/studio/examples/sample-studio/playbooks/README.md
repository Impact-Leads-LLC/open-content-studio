# Your playbooks

The craft the studio follows, written down so you can change it. These files are yours: setup copies them into
`studio/playbooks/`, and updating the plugin never touches your copies.

| File | What it decides |
|---|---|
| `content-strategy.md` | What to make, for which reader, how much, and which next step each piece asks for |
| `design.md` | How every graphic looks: colours, type, the accent, pictures, the looks that take turns |
| `hooks.md` | How first lines and cover lines are written |
| `posts.md` | The kinds of text post and when each one is used |
| `carousels.md` | How a carousel tells one idea, slide by slide |
| `reels.md` | Which moments make reels, how they're cut, and their covers |

## What wins when two files disagree

1. `brand/banned.md`, always.
2. Your other brand files: `brief.md`, `voice.md`, and `coach.md` with the rules you added in reviews.
3. These playbooks.
4. The studio's skills, which hold the process: file names, scripts, and the sizes the templates can fit.

## Changing a playbook

Edit the file, or tell Claude in plain words: "in my posts playbook, never use the invitation type", "captions in
capitals on my reels", "six reading slides at most". Claude changes the file and shows you the change. Each file ends
with a "Your changes" section; rules written there beat everything above them in that file.

To see a design change, say **"show me my look"**: the studio renders a post card in both looks so you can judge it.
To go back to the default for one file, say "reset my design playbook". The originals live in the plugin's
`templates/playbooks/` folder.
